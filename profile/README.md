# Quiten

**Quiten** is an open-source developer platform at **[quiten.tech](https://quiten.tech)** — built so developers can **share**, **discover**, and **build** tools and community projects without friction.

No algorithms. No curation bias. No noise. Just developers publishing things that matter to other developers.

> <img src="https://skillicons.dev/icons?i=github" height="14" align="absmiddle" /> Maintained by [@fy2ne](https://github.com/fy2ne) &nbsp;·&nbsp; Infrastructure research: [Essential Devs](https://github.com/Essential-Devs)

---

## ⬡ &nbsp; What Quiten Does?

<img src="https://skillicons.dev/icons?i=ts" height="16" align="absmiddle" /> &nbsp;**Developer Tools Registry** — discover and submit real tools the community actually built and ships

<img src="https://skillicons.dev/icons?i=git" height="16" align="absmiddle" /> &nbsp;**Open Source Publishing** — Quiten gives your project a place to land where developers look first

<img src="https://skillicons.dev/icons?i=cloudflare" height="16" align="absmiddle" /> &nbsp;**Edge-Native Infrastructure** — quiten.tech runs entirely on Cloudflare's edge network, zero cold starts

<img src="https://skillicons.dev/icons?i=supabase" height="16" align="absmiddle" /> &nbsp;**Community-Governed** — the Quiten platform is shaped by its users, not by a private roadmap
